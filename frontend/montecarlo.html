    Guía rápida · Monte Carlo

    Cómo simular una base de datos con Poisson o Exponencial

    El módulo genera números pseudoaleatorios u ∈ (0, 1) y los transforma con la función inversa de la distribución elegida. Cada variable produce una columna de la base de datos y cada observación produce una fila.

    Poisson · variable discreta

    λ Media de ocurrencia
    Cantidad promedio de eventos por intervalo. Ej. 4 llegadas por hora. Debe ser mayor que 0 y como máximo 10,000.
    k Valor simulado
    Entero no negativo. Se elige el menor k cuya probabilidad acumulada F(k) supera el número u generado.
    P Probabilidad
    P(X = k) = e^(−λ) · λ^k / k!. La tabla muestra el intervalo [F(k−1), F(k)) que produce cada valor.

    Ejemplo: λ = 4 y 1,000 observaciones generan una columna con media cercana a 4 y desviación cercana a 2.

    Exponencial · variable continua

    b Media
    Tiempo promedio entre eventos. Ej. 2.5 minutos. También puedes ingresar la tasa λ; el sistema muestra la equivalencia b = 1/λ.
    x Valor simulado
    x = −b · ln(u). El número u se mantiene dentro de (0, 1) para evitar logaritmos de cero.
    f Densidad
    f(x) = (1/b) · e^(−x/b). La media y la desviación estándar teóricas son iguales a b.

    Ejemplo: b = 2.5 y 1,000 observaciones producen una media cercana a 2.5 y un histograma decreciente.

    Parámetro global o personalizado

    G Global
    Todas las variables usan el mismo parámetro. Es la opción más rápida para comparar réplicas independientes.
    V Personalizado
    Asigna un nombre y un parámetro distinto a cada variable. En Exponencial puedes elegir media o tasa por variable.

    Confianza y semilla

    IC Confianza
    Nivel del intervalo para la media: 90 %, 95 % o 99 %. El intervalo usa el error típico s/√N y el valor z correspondiente.
    u Semilla
    Si la indicas, la misma configuración reproduce la misma base. Si la dejas vacía, se genera una semilla automática y se guarda en el historial.

    La base se pagina de 50 en 50 filas. El interruptor «Mostrar u» permite ver el número pseudoaleatorio de las primeras tres variables para comprobar manualmente la transformada inversa. Los reportes PDF e impresión incluyen el resumen, la tabla de transformada o frecuencias, las gráficas y una muestra de las primeras 50 observaciones.
